# Documentation

This directory contains all project documentation organized by category.

## Structure

- **`summaries/`** - Completion summaries for PRs, phases, and major features
- **`guides/`** - Setup guides, deployment instructions, and how-to documentation
- **`investigations/`** - Investigation reports and analysis documents
- **`fixes/`** - Bug fix summaries and resolution documentation
- **`plans/`** - Feature plans, implementation plans, and task lists
- **`tests/`** - Test data and test prescription examples
- **`prd/`** - Product Requirements Documents
